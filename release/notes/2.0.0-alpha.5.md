# RCA Scoring 2.0.0-alpha.5

日常软件缺陷 RCA 的研究候选预发布版。六领域、24 项保持诊断输出，不生成综合分。

- 按模式、来源种类固定审查对象与材料可得性；报告漏项和补丁事实不再混为同一评价对象。
- 质量分和陈述真假仍由模型判断，逐轮原样保存；程序不预填、修改或投票替换分数。
- 可复核的失败记录仍属于实际执行，不能被误写成未执行；虚假的通过主张独立要求修订。
- 细化部分信息与当前测试上下文的规则，补充固定版本完整函数证据。
- 完成 12 例三轮、36 份评判及 44 项本地测试；所有预设重复性门槛通过，开发失败完整保留。

详见[稳定性实测报告](../../docs/reports/stability-2026-10-25.md)。结论限于该固定开发验收集和
gpt-6-astra/medium 的结构化输入，不等于专家准确率、自由文本抽取稳定性或独立留出验证。
本次没有运行上游 Go 测试；没有将合成执行记录称为真实成功测试。

技能 ZIP 只包含 10 个运行源文件与 2 个生成的版本/清单文件。研究、案例、测试与工具均在
仓库的独立目录；不随安装包交付。安装见[说明](../../docs/install.md)。

来源约定使用 context.review_contract = "1.0"。旧输入仍可读取，但不承诺相同来源状态稳定性。
评价对象与 V2 记录质量含义已明确，旧 alpha 分数不可直接与此版本作数值比较。
应标记 Pre-release，尚不宜作为无需人工复核的生产标准。
