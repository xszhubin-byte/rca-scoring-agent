## 公开证据收集

- 50/50 个 Apache Camel K PR 已固定 base、head 和 merge-base SHA。
- 累计 517 个变更文件，全部返回补丁；文件数量、增删行数通过校验。差异是聚合 merge-base 到 head，覆盖多提交变化，但不包含完整仓库上下文。
- 取得 561 条 check-run、486 条工作流记录；50 个代表性工作流展开为 123 个作业、336 个步骤。
- 30 个案例修改测试相关文件。这不是 30 个缺陷已获回归验证的结论。
- 每例一份代表性作业日志下载尝试，50 次均返回 HTTP 410。不能核验具体断言运行情况；也不能由此推断测试失败。

证据见 [snapshots.json](evidence_v1_4/snapshots.json)，保留来源、取证时间、固定版本、差异、状态、步骤和失败信息。代码片段来源于 Apache Camel K，随附上游 LICENSE/NOTICE；不宣称本项目创作了这些补丁。

## 实际运行的 V1.4 基线

- Codex CLI `0.164.0-alpha.11.1`，使用已登录账号；没有运行 Claude CLI。
- 10 个首轮批次覆盖 50 个真实 PR；另外选取 5 个案例各复测两次，共 12 次独立 CLI 调用、60 个案例评判记录。
- 首轮 6 个 PR 正文可作探索性 `pr_author_proxy`。规范性、相关性与深度的分项结果见 [case_summary.csv](codex_v1_4/case_summary.csv)。没有 Owner RCA，不给原作者的正式 RCA 综合评分。
- 真实性仍存在提交信息或其他事实缺口；防范维度缺少执行证据，全部综合分为空。比较接口虽然返回提交信息，但首轮模型包仅保留 PR 说明、版本及补丁，未包含提交消息；这一包设计限制明确记录，不把它说成 GitHub 无法获取。
- 10 次与首轮比较的代理资格判断中，7 次一致；这来自同 5 个案例，不能当作总体 70% 准确率。首轮与复测差异均保留在 [repeatability.json](codex_v1_4/repeatability.json)。
- 450/450 次受控校验器回归通过，对应 9 种独立合成规则 × 50 个案例 ID。不是 450 个独立真实缺陷。
- CLI 使用默认模型，捕获的事件未暴露实际解析的模型 ID；不能确保跨调用模型路由一致，因此重复性结果还受此限制。按批次保存输入 hash、CLI 版本、token 用量、耗时、退出码和输出。

没有独立人工金标准，没有专家 MAE/kappa，也没有本地重跑 Go/Kubernetes 测试。现有数据只能支持取证、行为检查和探索性分项评分，不能证明生产准确率。

## 体系重构结论

旧五维度把表达、证据可信度、因果解释与改进行动混合加权，而且存在概念重叠。不能证明五维最优，也不能只因更细就宣称六维更好。

[研究与设计审查](../references/v2-design-review.md) 比较 A 原五维、B 简化四领域、C 六领域诊断候选；逐条列明一手资料如何支持设计、哪些是本项目提出的假设。当前可执行 C 候选的领域为：

1. 问题定义与边界。
2. 失效机理与因果论证。
3. 引入与逃逸分析。
4. 修复充分性与变更风险。
5. 验证设计与执行。
6. 同类治理与行动闭环。

共有 24 个细项、120 个行为锚点。表达可用性、证据状态及闭环阶段独立报告，不合成排名；0、未知和不适用有不同语义。缺少原始 RCA 不阻断明确声明的产物审查模式。程序门槛拒绝跨 SHA 验证、CI 状态冒充断言执行、N/A 隐藏核心项，以及关键反证被高分补偿。

这些约束只能检查数据与声明的一致性，不能自动证明引用真的支持某项因果解释，语义仍需评审。

## V2 行为测试与修订

使用真实 PR #6665 的固定补丁构造 5 个**合成**输入：简洁说明、仅增加套话的冗长版、与补丁矛盾的互斥锁修复说法、没有 Owner 文本的产物审查、以及 CI 成功即推断具体回归通过的说法。

- 初次独立 CLI 调用：2/5 个行为检查通过。模型识别了补丁反证，但错误处理执行评分与成熟度；确定性程序拒绝了两个不合规输出。
- 发现协议矛盾：原 V2 执行子项低档锚点允许只凭作者声称打低分，程序却要求在缺少执行记录时用 unknown/null。修订统一了规则，并明确先判断证据再分配闭环阶段。
- 修订后独立 CLI 调用：5/5 个行为检查通过；所有输出满足程序门槛。简洁/冗长版的已知技术子项平均绝对差为 0，没有未知状态变化。
- 首次 [原始响应](v2_behavioral/model_response.json)、[失败结果](v2_behavioral/summary.json) 和 [协议快照](v2_behavioral/protocol_snapshot.json) 保留。修订后结果位于 [revision-02](v2_behavioral/revision-02/summary.json)。

这是对已见构造样本的定向修复回归，不是留出集测试；也不能把变化完全归因于协议修改，因为实际模型 ID 未被记录。尚未与 A/B 方案在同一专家标注集上做效果比较。研究候选不应升级为“已验证最优标准”。
