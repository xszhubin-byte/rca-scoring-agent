# RCA Scoring 2.0.0-alpha.1

这是面向日常软件缺陷 RCA 的研究候选预发布版。

## 此版本提供

- 六领域、24 个细项、120 个行为锚点。
- 证据支持、反证、未知及不适用的分离记录。
- 独立的闭环阶段与确定性校验器；不输出综合人员排名。
- 只包含运行资源的独立技能 ZIP、包清单和 SHA-256 校验值。

## 安装

下载 `rca-scoring-2.0.0-alpha.1.zip`，将其中的 `rca-scoring/` 放入项目的
`.agents/skills/`。安装文件夹中 `requirements.txt` 的依赖，再运行附带示例验证安装。
使用 `$rca-scoring` 显式调用。

## 验证与限制

当前仓库测试含规则、公开快照一致性、可重复打包和脱离仓库后的运行检查。
原有 50 个 PR 的 Codex CLI 记录、复测及 V2 首次失败/修订结果放在研发数据目录，未附带到安装包。

尚无独立人工金标准；具体回归运行日志缺失；既有 CLI 事件未记录实际模型 ID。
六领域的最优性与生产评分准确率尚未得到验证。
